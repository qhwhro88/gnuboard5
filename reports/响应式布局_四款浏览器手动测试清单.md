# 响应式布局 四款浏览器手动测试清单

> 测试对象：https://yiwupage.com
> 范围：桌面主题流式响应改造 + 800px 断点堆叠修复
> 涉及改动：`theme/basic/css/default.css`、`theme/basic/skin/latest/pic_block/style.css`、`extend/version.extend.php`
> 对应提交：`c163c1b` feat: 桌面主题流式响应改造，修复800px断点下横向溢出和元素重叠问题

---

## 一、通用准备（每款浏览器都做）

1. 使用**无痕/隐私窗口**打开站点，避免旧 CSS 缓存干扰。
2. 打开开发者工具，进入**响应式/设备模拟模式**：
   - Chrome / Edge：`F12` → `Ctrl+Shift+M`（macOS 为 `⌘⇧M`）
   - Firefox：`F12` → `Ctrl+Shift+M`
   - Safari：先开启「开发」菜单（偏好设置 → 高级 → 勾选「在菜单栏显示开发菜单」），再 `⌥⌘M`
3. 每次切换宽度后等待 1 秒再观察，确保样式已重排。

---

## 二、核心验证点（每档宽度都检查 3 件事）

1. **无横向滚动条**：页面右侧不出现水平滚动条，`scrollWidth ≤ clientWidth`。
   - 可在 Console 输入：`document.documentElement.scrollWidth - document.documentElement.clientWidth`，结果应 ≤ 0。
2. **文字不重叠**：标题、按钮、链接之间无叠字、无挤压。
3. **元素自动下移**：窄屏时头部元素纵向堆叠，而非横向挤压。

## 四、800px 断点专项检查（本次改动核心）

在 800px 宽度下，逐项确认：

1. **头部结构**：`#hd_wrapper` 高度自适应（不再是固定 140px）。
2. **Logo**：居中显示，图片不超出容器（`#logo` 取消浮动）。
3. **搜索框**：居中、单行，输入框宽度 ≈ 容器宽度减去按钮 60px。
4. **登录/注册链接**：居中横向排列，位于搜索框**下方**（`position` 从 `absolute` 变为 `static`）。
5. **顶部快捷栏**（FAQ / Q&A / 새글 / 접속자）：居中显示，不右浮动挤压。
6. **主内容区 `#container`**：占满全宽，不再与侧边栏并排。
7. **侧边栏 `#aside`**：移到主内容**下方**，占满宽度。
8. **最新帖图片区**（`.latest_top_wr` / pic_block 皮肤）：`scrollWidth == clientWidth`，**无横向溢出**（这是负边距修复的关键验证点）。

判定标准：头部 Logo、搜索框、登录链接三者的纵向位置**依次递增**（logo 在最上、搜索框居中、登录在最下），且视觉上顶部对齐、无左右错位。

## 五、四款浏览器差异化关注点

| 浏览器 | 特别关注 |
|---|---|
| **Chrome** | 基准浏览器，按上面全部步骤执行 |
| **Firefox** | 重点看 `calc()`（`#container` 的 `calc(100% - 270px)`、搜索框的 `calc(100% - 60px)`）在 801~1200px 间的计算是否正常 |
| **Safari** | 重点看 `position:static` 覆盖 `.hd_login` 绝对定位是否生效；字体渲染差异 |
| **Edge** | 与 Chrome 同为 Chromium，结果应与 Chrome 一致，若有差异需记录 |

---

## 六、通过 / 失败判定

- **通过**：四款浏览器、全部宽度档位下，均满足「无横向滚动条」「无文字重叠」「窄屏纵向堆叠」。
- **失败**：任一浏览器、任一宽度出现横向滚动、文字重叠、元素错位、头部导航缺失、分页报错。
- **失败记录格式**：浏览器 + 宽度 + 页面路径 + 截图 + Console 报错信息，反馈定位。
